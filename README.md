# Student Result Alert System

A web-based application developed using **Python (Flask)**, **MySQL**, and **HTML/CSS** to manage student academic records and send automated result notifications via email.

---

## 🚀 Features
- 📊 Manage and store student results efficiently
- 📧 Automated email notification system for result updates
- 🛠️ Admin dashboard for uploading and managing results
- 🔐 Secure backend with structured database design

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS  
- **Backend:** Python (Flask)  
- **Database:** MySQL  
- **Libraries:** smtplib  
- **Tools:** Git, GitHub
